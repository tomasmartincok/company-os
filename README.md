# company-os

Prenosný súborový Second Brain a pracovný systém firmy pre Codex alebo Claude Code, s voliteľným Obsidianom.

**Aktuálny stav: kompletná špecifikácia v1.3 pred tvorbou inštalátora.** Repozitár zatiaľ obsahuje dokumentáciu zadania.

[Prečítať špecifikáciu v1.3](docs/specifikacia.md)

Zadanie obsahuje Olivera, priečinky zamestnancov s vlastnými workflowmi, procesný generátor, tabuľu dokončenia s otázkami, osobný a firemný profil, znalostnú bázu a denné zápisky. Inštalácia a nastavenie sú vedené chatom; cieľové platformy sú macOS a Windows. Revízia spresňuje metadata/prepojenia, overenie releasu, ochranu personalizácie, zápisy, synchronizáciu a obnovu aktualizácií.

Verejný dokument je samostatne použiteľný na review bez súkromného Second Brainu. Obsahuje 18 akceptačných kritérií a plán pilotu. Publikácia špecifikácie nepotvrdzuje funkčný inštalátor ani workshopový release. Detailný kontrolný prompt autor odovzdáva iba v chate.
